# ChatGPTへの指示文（2つのメッセージに分けて送ります）

## 1通目：モチーフを伝える

`motif-animal.md` / `motif-round-face.md` / `motif-person.md` のうち、
選んだ1つの内容をそのままコピーしてChatGPTに送ってください
（手持ちの画像がある場合は、この1通目の代わりにその画像を添付してください）。

## 2通目：この指示文を全文コピーして送る

あなたはこれから、LINE Creators Marketに出品できる「動くLINE絵文字（アニメーションスタンプ）」用の
表情差分イラストを作る手伝いをします。今伝えたキャラクターの見た目（またはさっき添付した画像のキャラクター）を保ったまま、
以下の条件を守って、表情差分を1枚ずつ生成してください。

## 表情セット

- 表情セット（5枚以上。迷ったら次の5つでOK）：
  1. 通常の笑顔
  2. 大笑い
  3. 驚き
  4. 困り顔
  5. 照れ

## 条件

- 全フレームで「同じキャラクター」に見えるよう、輪郭・配色・構図を統一してください
  （表情パーツ以外は動かさない）
- 背景は無地の単色（できれば白）にしてください。後工程で透過処理します
- 正方形に近い構図で、キャラクターを画面中央に大きく配置してください
- 1回の生成につき1つの表情だけを描いてください（複数表情を1枚にまとめない）

## 進め方

1. 上記の表情セットの数だけ、1枚ずつ順番に画像を生成してもらう
   （「1. 通常の笑顔」→「2. 大笑い」…の順に、都度「次は◯◯の表情で」と指示する）
2. 生成した画像をすべてダウンロードし、ファイル名を `001.png`, `002.png`...の連番にする
3. 無料のオンラインツール（例: apng-maker.vercel.app）で、連番画像をアップロードしてAPNGに結合する
   - 背景を透過にする機能があれば使う（なければ画像編集アプリで白背景を透過に抜く）
   - キャンバスサイズは320×270px以内、長辺270px以上にリサイズする
   - フレーム間隔（duration）は150〜250ms程度、ループ回数は1〜4回に設定する
4. 書き出したAPNGファイルのサイズが300KB以内か確認する
   （超えている場合はフレーム数を減らす、または画像を圧縮する）
5. LINE Creators Marketへの申請方法はページの「LINEへの申請方法」セクションを参照してください。

※ ChatGPTのみルートでは、Codexルートのような文字入れの精度は保証できません。
　 セリフを入れたい場合は、上記の無料ツールや画像編集アプリの文字入れ機能で代用してください。
