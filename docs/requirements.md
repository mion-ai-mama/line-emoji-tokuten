## 1. プロジェクト概要

Instagramリールの特典として配布する、スマートフォン最優先の1ページ完結ガイド。
「動くLINE絵文字」をCodex（コード実行ができるAIエージェント）またはChatGPT（画像生成のみ）のどちらでも
作れるように、2つのルートを1つのキットとして案内する。

競合LP（one-lp-1.com/lp/line-emoji/）の構成を参考にしつつ、配布するキットの中身は完全オリジナルで新規作成する
（競合が配布するファイルをそのまま流用しない）。

### 成功指標

| 種別 | 指標 |
|---|---|
| 定量 | 横スクロール0件（320 / 375 / 1280px）／JSエラー0件／プロンプトが全箇所ワンタップでコピー可能 |
| 定量 | キットZIPのダウンロードが正常に完了する（GitHub Pages配信・100MB制限内） |
| 定性 | Codexを持たない読者でも「ChatGPTだけ」ルートで最後まで迷わず到達できる |
| 定性 | 自分の絵がない読者も、モチーフ選択だけで迷わず次に進める |
| 定性 | 誇張表現・未確認の断定を含まない |

### 想定読者

AI初心者／副業・個人事業化志向／「絵が描けない」という障壁を感じている層／
Codex利用者とChatGPTのみの利用者の両方／スマートフォンでの閲覧・操作が中心。

## 2. 配布キットの仕様（このページの核）

### 2.1 LINE公式の技術仕様（LINE Creators Market・動く絵文字）

キットが生成する成果物は、以下の公式仕様を満たす必要がある。

| 項目 | 仕様 |
|---|---|
| フォーマット | APNG |
| キャンバスサイズ | 320×270px以内（どちらかが270px以上） |
| フレーム数 | 5〜20フレーム |
| ループ回数 | 1〜4回 |
| 再生時間 | 4秒以内 |
| ファイルサイズ | 1個あたり300KB以下 |
| 出品 | LINE Creators Marketへの個人登録・申請は無料（審査あり） |

### 2.2 モチーフ選択フロー（自分の絵がない読者向け）

読者の起点は2パターン。

1. **手持ちの画像がある** → その画像をCodex/ChatGPTにそのまま添付して進める
2. **手持ちの画像がない** → 以下のモチーフから選んで、AIに新規デザインを提案させる
   - 動物（うさぎ・ねこ等）
   - 丸顔・絵文字風キャラ
   - 人物（お母さん・お父さん・女性・男性など）

> **注記（人物モチーフの技術的留意点）**: 表情差分を複数フレーム作る際、人物は動物・丸顔キャラより
> 特徴点が多く、フレーム間で顔がブレやすい傾向がある。キットのプロンプトには
> 「シンプル・ちびキャラ風で描く」など一貫性を保つための指示を明記する。

### 2.3 表現セット

「表情差分パック」を基本とする（例: 笑う／驚く／困る／照れる等）。競合と同じ路線。

### 2.4 文字入れ（オプション機能）

セリフ・短い文字（「了解！」「OK」等）を入れたい読者向けに、**AIの画像生成に直接文字を描かせない**。
画像生成モデルは文字を正確に描けないため、次の2段構成にする。

1. AIでキャラの表情フレームを生成（文字なし）
2. Codex側でPillow（`ImageDraw` + フォント指定）により、生成済みフレームに文字をピクセル単位で正確に合成

ChatGPTのみのルートでは、文字入れは「無料のAPNG結合ツール側で対応できる範囲」に留める旨を案内する
（Codexルートほどの精度は保証しない）。

### 2.5 2ルート構成

| ルート | 対象 | 技術的な流れ |
|---|---|---|
| Codexルート | Codexを使える読者 | ①モチーフ確定 → ②Codexが表情フレームを生成 → ③（任意）Pillowで文字合成 → ④pyAPNG等でAPNGに自動合成 → ⑤LINE仕様に沿ったバリデーション |
| ChatGPTのみルート | ChatGPTの画像生成のみの読者 | ①モチーフ確定 → ②ChatGPTで表情差分の連番静止画を生成 → ③無料Webツール（apng-maker.vercel.app 等）でAPNGに結合 → ④LINE仕様に合わせてリサイズ・確認 |

両ルートとも、配布するキット（ZIP・プロンプトテキスト）はオリジナルで新規作成する。

## 4. データ設計概要

永続データなし。

## 5. セキュリティ要件

- 外部リンクはすべて `target="_blank"` + `rel="noopener noreferrer"`
- 入力フォーム・個人情報の収集なし
- 外部スクリプト・トラッカーの読み込みなし
- GitHub Pages は HTTPS 配信
- 配布キットZIPは自作コンテンツのみを含む（競合ファイルを一切含めない）

## 6. 技術スタック

HTML5 / CSS3 / Vanilla JavaScript。ビルドツール・パッケージ依存なし。

## 7. 外部サービス一覧

| サービス | 用途 |
|---|---|
| GitHub Pages | 静的ページ・キットZIPの配信 |
| LINE Creators Market | 読者が完成した絵文字を出品する先（ページからは手順案内のみ） |

外部APIの呼び出しはなし。
