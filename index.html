LINE絵文字って何？

LINEには、トークで使える「絵文字」を自分で作って
LINE Creators Marketに出品できる仕組みがあります（8〜40個の「セット」で出品）。

このガイドでは、AIとの会話でキャラクターを決め、
表情・生活シーン・アイコン・ふきだし文字の40種類を1セットとして一括生成する方法を、
Codexが使える人・ChatGPTだけの人、両方の手順で紹介します。

今回作る40個のセット内容

LINEの絵文字は8〜40個のセットで出品します。
このガイドでは、次の40種類（表情20・生活シーン10・単独アイコン3・ふきだし文字7）を 1セットとして作ります（あとから内容を変えることもできます）。

  • 001〜020 表情（こんにちは・ありがとう・OK・大笑い・ごめんね・がんばる など20種類）
  • 021〜030 生活シーン（スマホを見る・パソコン作業・コーヒーブレイク など10種類）
  • 031〜033 単独アイコン（ハート・星・チェックマーク）
  • 034〜040 ふきだし文字（ありがとう・おつかれさま・OK！ など7種類）

補足

40種類の内容は、キット内の 40-emoji-set-plan.json が正本です。テーマを変えたい場合はこのファイルのmeaning・descriptionを書き換えてください。

Codexで作る

キャラ提案から画像生成、ZIP作成まで、Codexが会話の中で一気に進めます。

公式サイトからCodexを入手する
  1. 上のボタンからCodexを入手し、起動する
  2. 下の「必要な2ファイルをダウンロード」からZIPを取得し、解凍した2ファイルすべてを作業フォルダに置く
  3. 下のプロンプトを全文コピーしてCodexに貼り付ける
  4. Codexが提案するキャラ候補A/B/Cから選ぶ（または自分の画像を送る）
  5. 「マスター画像生成」と送る（キャラの基準画像ができます）
  6. できあがったら、続けて「40個生成」と送る（40個を1枚にまとめて生成します）
  7. できあがったら、続けて「zip」と送る（見分けの確認をしてからZIPが完成します）
  8. 気になる番号があれば「029だけ修正」と送る（直ったら「zip更新」と送る）

途中で止まってしまったら

生成の返事が来ないまま止まってしまったり、区切りのいいところで止まってしまったりしても、壊れたわけではありません。「続けて」とだけ送れば、続きから再開できます。

# Codexへの指示文（このまま全文貼り付け）

## 事前準備

1. 公式サイトからCodexを入手し、起動する
2. キットの 40-emoji-set-plan.json / emoji_pipeline.py を
   作業フォルダに置く（2ファイルとも同じフォルダに置くこと）
3. 下の指示文を全文コピーして、Codexに送る

---

あなたはこれから、LINE静止絵文字セット（40個）の制作を最後まで実行する担当です。

説明だけで終わらず、必要な場面では実際に画像生成・コード実行を行い、
最終的にダウンロード可能なZIPファイル（output/line-emoji-set.zip）まで完成させてください。

作業フォルダにある以下のファイルを使用します。

- 40-emoji-set-plan.json（40個の構成の正本。番号・意味・説明はここから読む）
- emoji_pipeline.py（グリッド画像の切り出し・レビュー・ZIP作成はこの実装を優先する）

## 仕様（LINE公式・静止絵文字）

- キャンバスサイズ：180×180px固定
- ファイル形式：PNG（静止画。アニメーションではない）
- ファイルサイズ：1個あたり1MB以下
- 背景：透過必須
- セット内の個数：40個（今回の構成）
- トークルームタブ画像：96×74pxを1個

## 最重要：新規制作の最初の応答

まだキャラクターが決まっていない場合は、手順説明だけを返してはいけません。
最初の応答で、すぐにキャラクター候補A/B/Cを3案提案してください
（「動物」「丸顔・絵文字風」「人物・ちびキャラ」の3系統で、種類・輪郭・体型・主色・線色・性格まで具体的に）。

ユーザーが「別の」と言った場合は新しい3案を、A/B/Cを選んだ場合はそのキャラクターを
以後ずっと固定して使ってください。自分の画像が送られた場合はそれを最優先します。

## 毎ターン操作を判定

- 「マスター画像生成」→ 採用済みキャラクターの基準画像を1枚生成し、以後の参照として固定する
- 「40個生成」→ 40-emoji-set-plan.jsonのitems（40個）に沿って、キャラの見た目を保ったまま
  1枚の画像（8行×5列）として生成し、grid.pngに保存する。031〜033はキャラを出さずアイコンのみ、
  034〜040は吹き出し＋文字のみにする。distinctness_noteを参照し、紛らわしいペアを混同しない。
  時間がかかっても40個描き終えるまで応答を止めない（初心者は途中で止まると「できない」と
  誤解してやめてしまうため）。本当に続行できない技術的理由がある場合のみ途中で止めて理由を伝える
- 「zip」→ 画像生成は使わず、次を順に実際に実行する。
  1) python emoji_pipeline.py slice --grid grid.png --plan 40-emoji-set-plan.json --out-dir output
  2) python emoji_pipeline.py tab --source output/001.png --out output/tab.png
  3) python emoji_pipeline.py review --plan 40-emoji-set-plan.json --out-dir output
  （output/review/001.png〜040.pngができる。これを実際に見て、checklist_TO_FILL.jsonの
  checks（meaning_matches / no_semantic_duplicate等）を正直にtrue/falseで埋め、
  observationに見た内容を書く。省略・虚偽記入は禁止）
  4) python emoji_pipeline.py pack --plan 40-emoji-set-plan.json --out-dir output --zip output/line-emoji-set.zip --review output/review/checklist_TO_FILL.json
  （packはchecklistにfalse・未記入があるとエラーで停止しZIPを作らない。エラーの番号は
  「00X修正」で再生成し3〜4をやり直す。最大2回。直らなければ番号を挙げて案内する）
- 「029だけ修正」→ 指定番号だけをマスター画像を参照して単独で再生成し、output/029.pngを
  上書きする（40個全体は作り直さない）。番号を複数指定された場合も1個ずつ個別再生成する。
  再生成した番号はchecklistのその行をnullに戻す
- 「zip更新」→ 直近で再生成した番号だけを反映してZIPを作り直す

生成が途中で止まってしまった場合、ユーザーから「続けて」と送られたら続きから再開する
（最初からやり直さない）。

相手はプログラミングをしない読者です。ファイル名・コード上の変数名・エラー文の原文
（emoji_pipeline.py、grid.png、no_semantic_duplicate、ModuleNotFoundError等）を
そのまま出さず、日常の言葉に言い換えてください。各応答の最後に「現在／今回できたこと／次の操作」を
平易な言葉で短く示し、未実行の処理を完成と書かないでください。
LINEへのアップロードや審査申請はユーザーが行います。実行したと装わないでください。
必要な2ファイルをダウンロード（ZIP）

ChatGPTだけで作る

ChatGPTの「コード実行」機能を使い、キャラ提案からZIP作成までを1つのチャットで完結させます。

必要な環境

この方法は、ChatGPTで「コード実行（Data Analysis／Code Interpreter）」が使えるプラン・環境が必要です。使えない場合は「Codexで作る」をご利用ください。

  1. 下の「必要な2ファイルをダウンロード」からZIPを取得して解凍する
  2. ChatGPTで新規チャットを開き、解凍した2ファイルすべてを添付する

  7. できあがったら、続けて「zip」と送る（見分けの確認をしてからZIPが完成します）
  8. 気になる番号があれば「029だけ修正」と送る（直ったら「zip更新」と送る）

LINEへの申請方法

完成したPNGファイルは、「LINE Creators Market」で公式サイトを検索し、
個人クリエイターとして登録・申請することで出品できます（登録・申請は無料、審査があります）。

  • フォーマット：PNG（静止画）
  • キャンバスサイズ：180×180px固定
  • ファイルサイズ：1個あたり1MB以下
  • 背景：透過必須
  • セット内の個数：8〜40個（1個単位で調整可）
  • メイン画像：セットの中から4個を選ぶ（ストア掲載用）
  • トークルームタブ画像：96×74pxを1個
  • 提出用ZIP：20MB以内

これらの数値は emoji_pipeline.py が自動でチェックしてくれます。

うまくいかないとき

お使いのプラン・環境ではコード実行（Data Analysis／Code Interpreter）が使えない可能性があります。「Codexで作る」ルートに切り替えるか、コード実行が使えるプランをご確認ください。

「マスター画像生成」で作った基準画像をもう一度参照するよう伝え、ブレている番号を「00X修正」で再生成してください。人物モチーフの場合は、より簡略化した「ちびキャラ」で描き直すよう伝えると安定しやすくなります。

「zip」の工程で行う目視レビュー（checklist_TO_FILL.jsonのno_semantic_duplicate）で気づけるようになっています。指摘された番号を「00X修正」で再生成してください。それでも似てしまう場合は40-emoji-set-plan.jsonのdescriptionで、その番号だけ手の位置や小物を大きく変えると直りやすいです。

emoji_pipeline.pyは、背景が透過されていない場合に白背景を自動で透過処理します。背景が白以外（グラデーションや模様など）の場合は、「背景を無地の白にして」と伝えて生成し直してください。

キャラクターの色数や模様の細かさを減らして生成し直してください。emoji_pipeline.pyがエラーで教えてくれます。

キット内の40-emoji-set-plan.jsonのmeaning（意味）・description（見た目の説明）を書き換えてから「40個生成」をやり直してください。

他者のキャラクターやイラストに酷似していないか、仕様（サイズ・枚数・ファイルサイズ）を満たしているかを見直してください。審査基準はLINE Creators Market公式サイトの最新情報をご確認ください。
